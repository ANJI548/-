# 反缩水雷达 · mcd-shrink-radar

> 麦当劳 1024 程序员节参赛作品。把“汉堡是不是变小了”从主观感受变成可量化的数据。

## 🎯 项目简介

“缩水式通胀”是社交媒体上的高频吐槽：价格在涨，汉堡却在变小。但“变小了”往往只是主观感受，缺少量化依据。

**反缩水雷达**通过 MCP 实时接口获取麦当劳官方菜单数据，结合历史基准，计算每款产品的**单位价格（元/100kcal）**，给出 1~5 星的性价比评分，并在评分过低时自动推荐同价位、单位价格更优的替代品。

- **取数交给 MCP**：调用麦当劳官方 MCP 接口获取实时菜单和营养数据。
- **算术交给代码**：核心逻辑纯函数零依赖，保证结果可复现。
- **表达交给 Agent**：LLM 只负责组织语言输出，不做数值估算。
- **离线可复现**：支持降级使用本地快照数据，评委无需 Token 即可跑通演示。

## 🚀 核心能力

- **单品性价比评分**：输入单品名（如“双吉”“麦辣鸡腿堡”），自动计算单位价格，对比历史基准，给出 1~5 星评分。
- **套餐缩水诊断**：输入套餐名（如“随心配”），拆解套餐内单品原价，计算优惠力度，判断是“明涨”还是“暗缩”。
- **替代品推荐**：当单品评分 ≤ 2 星时，自动从菜单中筛选同价位、单位价格更优的替代品。
